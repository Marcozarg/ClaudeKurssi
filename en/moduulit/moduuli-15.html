The API and your subscription are different things

So far you have used Claude in claude.ai and Claude Code with a subscription (Free, Pro or Max). The Claude API is how you call Claude from your own code: a script, a service or an integration. It is a different product from the subscription:

  • Separate billing: the API is billed by use, per token, in the Claude Console (platform.claude.com). A Pro or Max subscription does not include API use, and API use does not count against your subscription's limit.
  • API key: your code identifies itself with a key you create in the Console. The key is a secret just like a password (module 0): it does not belong in code, in git, in a chat or in a screenshot.
  • Spend limits: set a monthly limit in the Console before you run anything in a loop. A buggy loop can spend money quickly.
At work, the API key and the billing usually belong to the organization. Ask before you create a key for work or put work data into an API call.

A first call in Python

Install Anthropic's Python library and give the key as an environment variable. The PowerShell line below sets the variable for this window only, so the key is not left in a file.

pip install anthropic
$env:ANTHROPIC_API_KEY = "paste-the-key-here"

Save this as first.py and run python first.py:

import anthropic

client = anthropic.Anthropic()
response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "Explain in one sentence what DNS does."}],
)
for block in response.content:
    if block.type == "text":
        print(block.text)
print("tokens in:", response.usage.input_tokens, "out:", response.usage.output_tokens)
  • anthropic.Anthropic() reads the key from the ANTHROPIC_API_KEY variable. Do not write the key into the code.
  • model is the model's ID, max_tokens the upper limit of the answer.
  • The answer is a list of blocks; the text blocks are printed. usage tells you how many tokens you pay for.

Choosing a model, and the price

The same price list as in module 0, now with each model's ID. Prices in dollars per million tokens, checked 11/2026 (Pricing):

ModelIDInputOutputWhen
Haiku 5.5claude-haiku-5-5$0.10$0.50Large amounts of simple work: classification, extraction. The price applies to prompts of up to 100,000 tokens.
Sonnet 5.5claude-sonnet-5-5$2$10Everyday code and text work, fast.
Opus 5.5claude-opus-5-5$4$20The default choice for demanding work.
Fable 5.1claude-fable-5-1$10$50The hardest tasks, when quality decides.

Do the sum before you run: 1,000 tickets with 2,000 tokens in and 300 out each is 2 million input tokens and 0.3 million output tokens. With Haiku that costs about $0.35, with Opus about $14. When a task is simple and repetitive, try the cheaper model first and check the result on a few examples.

The models think before they answer, and thinking is billed as output tokens. You set how much they think with output_config={"effort": "low"} (also medium, high, xhigh, max); a light task does not need high effort.

The Agent SDK in brief

One API call is one question and one answer. When you want a program that reads files, runs commands and takes many steps by itself, you need an agent. Three ways:

WayWhat you getWhen
API callAn answer to a prompt. You build the tools and the loop yourself.Classifying, summarizing, extracting in your own script.
claude -pClaude Code in a script or in CI (module 14).Claude Code as it is, run without a person.
Agent SDKClaude Code as a library for Python or TypeScript: built-in tools (files, commands, search), permissions, hooks and subagents.Your own program or service with an agent inside it.

The Agent SDK uses the same permissions and safety limits as Claude Code (modules 7 and 12): an agent that may run commands needs limits as tight as Claude Code does. Documentation and examples: code.claude.com/docs/en/agent-sdk.

1. A first API call

Needs: an API key in the Console, credit and Python 3. No key? Paste the script into a claude.ai chat (Free) and ask Claude to explain it line by line and say what it prints.

Run the script from "A first call in Python". Then change the model to claude-haiku-5-5 and run it again. Compare the answers and the token counts, and work out the price of each call with the prices in the table.

The script prints one sentence (for example "DNS turns domain names into IP addresses so that computers can find each other.") and the token counts, typically a few dozen in and from a few dozen to a few hundred out, because thinking counts as output. Each call costs less than a cent. If you get an authentication_error, the variable is missing or the key is wrong: set the variable in the same PowerShell window where you run the script.

2. Work out the cost before you run

Needs: nothing; a calculator or claude.ai (Free) is enough.

You plan to classify 500 tickets. Each has about 1,500 tokens in and 200 out. Work out the price with Haiku, Sonnet and Opus using the prices in the table.

Show example answer

The input is 500 × 1,500 = 750,000 tokens (0.75 million), the output 500 × 200 = 100,000 tokens (0.1 million). Haiku: 0.75 × 0.10 + 0.1 × 0.50 = about $0.13. Sonnet: 0.75 × 2 + 0.1 × 10 = $2.50. Opus: 0.75 × 4 + 0.1 × 20 = $5. Classification is simple work, so start with Haiku and check the result on a few tickets by hand.

3. Classify tickets

Needs: an API key, credit and Python 3. No key? Give the same instruction and tickets in a claude.ai chat (Free) and compare the result with the example answer.

The script classifies three made-up tickets with Haiku at low effort. Run it and check whether the categories are right. Then add a ticket of your own to the list.

import anthropic

client = anthropic.Anthropic()
tickets = [
    "The printer on the third floor does not print, the light blinks orange.",
    "I forgot my password and cannot log in to my computer.",
    "I need a Visio licence for a project.",
]
for ticket in tickets:
    answer = client.messages.create(
        model="claude-haiku-5-5",
        max_tokens=1000,
        output_config={"effort": "low"},
        system="Classify the IT ticket into one category: hardware, accounts, software or other. Answer with the category name only.",
        messages=[{"role": "user", "content": ticket}],
    )
    category = next(b.text for b in answer.content if b.type == "text").strip()
    print(f"{category}: {ticket}")
Show example answer

The expected result: the printer is hardware, the password accounts and the Visio licence software. The system prompt (system) is the same in every call, and only the ticket changes. If the category comes back as a sentence and not a single word, make the instruction more precise or ask for the answer as JSON. Before you run thousands of tickets, check the result on a small sample by hand and work out the price as in exercise 2.

Optional: tools, caching and more

  • Tool use: you define a function's name, description and parameters, and Claude asks to call it when it needs information or an action. Your code runs the function and returns the result. This way Claude can, for example, look up a ticket's status in your own system. Guide: Tool use.
  • Prompt caching: when the same long beginning (system prompt, instructions, a document) repeats in many calls, it can be cached, and read again it costs about a tenth. The simplest way is one parameter: 
    response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=16000,
    cache_control={"type": "ephemeral"},
    system="A long instruction that is the same in every call...",
    messages=[{"role": "user", "content": "Summarize this ticket."}],
)
print(response.usage.cache_read_input_tokens)
    Caching works only when the beginning is exactly the same in every call: a timestamp at the start of the prompt breaks it. Guide: Prompt caching.
  • Batches: when the result may come later, the batch API costs about half the normal price.
  • Why the answer ended: response.stop_reason is usually end_turn; max_tokens means the limit was reached, and refusal that the model declined. Check it before you read the answer.
