Claude Code: installation

Core ~20 minOptional ~20 minPro / Max

What is Claude Code?

Claude Code is a version of Claude that runs on your machine, in your own folder. It reads files, edits them and runs commands (for example PowerShell scripts and git commands) when you approve it. In chat you copy text to Claude and back. In Claude Code, Claude works directly with your files.

  • Good for working on scripts, logs, guides and configurations, not just programming.
  • Available on the command line, as a VS Code extension and on the Code tab of the desktop app. They all use the same settings.
  • Using it consumes the same usage limit as claude.ai (module 0, usage limits).
Claude Code requires a Pro, Max, Ultra, Team or Enterprise plan or a Console account. A free claude.ai account does not include Claude Code. No Pro? Follow the instructor's demo or work with a partner.

Before installing

  • Windows: Windows 10 version 1809 or newer, or Windows Server 2019 or newer.
  • Hardware: at least 4 GB of RAM, an x64 or ARM64 processor, an internet connection.
  • Administrator rights are not needed. Do not open the terminal as administrator.
  • Git for Windows is optional but recommended. Without it Claude Code uses PowerShell to run commands; with it, it uses Git Bash. Module 8 needs git in any case.

The Claude Code version tested for this course is 2.1.318 (checked 11/2026). In a newer version the menus and commands may differ slightly; the installation guide is always up to date.

Installing on Windows

Open PowerShell (from the Start menu) and run:

irm https://claude.ai/install.ps1 | iex

The installation shows no progress while it downloads. When it is done, open a new terminal window and check:

claude --version

The command prints the version number. If the terminal says claude is not a known command, the installation folder is not in the PATH variable yet; a new terminal usually fixes it.

First launch and signing in

  1. Go to the folder where you want to work, for example a practice folder: cd %USERPROFILE%\Documents\harjoitus (CMD) or cd $env:USERPROFILE\Documents\harjoitus (PowerShell).
  2. Type claude.
  3. The first time, Claude Code opens the browser. Sign in with the same Claude account that has Pro or Max.
  4. Claude Code asks whether you trust the folder. Answer yes only for folders whose contents you know.
  5. Type a message, for example "What is in this folder?", and watch how Claude asks for permission to read files.
[KUVA: m6-login - the browser sign-in window and a ready session]

You can check the state of the installation with the command claude doctor. The native installation updates itself; other installation methods need a manual update (claude update for the native installation).

The VS Code extension

  1. Open VS Code (version 1.94.0 or newer).
  2. Open Extensions (Ctrl+Shift+X), search for "Claude Code" and choose Claude Code for VS Code, published by Anthropic. The extension's identifier is anthropic.claude-code. Choose Install.
  3. Open Claude: click the Spark icon in the top right corner of the editor (visible when a file is open) or the Claude Code text in the bottom bar.
  4. If the extension does not show after installing, restart VS Code or run Developer: Reload Window from the command palette (Ctrl+Shift+P).

The benefit: Claude sees your open file and selection, and changes appear in the editor as a diff that you accept or reject. Alt+K adds a reference to the current file and selection to the conversation.

The desktop app: the Code tab

If you have already installed the Claude desktop app (module 4), Claude Code is on its Code tab. A separate command-line installation or Node.js is not needed.

  1. Open the app and sign in.
  2. Choose Code at the top of the sidebar.
  3. Choose Local as the environment and open the working folder (Open folder...).
  4. Choose a model and type what Claude should do.

The permission mode shows under the prompt field: Manual asks before changes, Accept edits accepts file changes by itself, Plan only plans. Start with Manual. You see the changes in the diff view.

Exercises

1. Install and check

Requires: a Pro plan. No Pro? Follow the instructor's demo (Max) or work with a partner.

Install Claude Code with PowerShell, open a new terminal and sign in. Ask Claude which Windows version the machine has and whether git is installed. Compare the answer with the output of the commands winver and git --version that you run yourself.

Show example answer

Claude suggests commands (for example Get-ComputerInfo and git --version) and asks permission to run them. When you approve, it reports the version and whether git is available. If git is missing, Claude says so from the error message; install Git for Windows before module 8. Check that the version Claude reports matches the winver window.

2. Ask about files

Requires: a Pro plan. No Pro? Follow the instructor's demo (Max) or work with a partner.

Make an empty folder with one PowerShell script (for example one that checks disk space) and a small log file. Start claude in the folder and ask: "What is in these files? Summarize the script in two sentences and tell me what the log shows." Notice how Claude asks permission to read the files.

Show example answer

Claude reads the files in the folder (reading in the working folder usually does not ask permission), summarizes the script and picks out the repeated errors from the log. Check that the summary matches what the script actually does: open the script and compare. If Claude suggests changing the script, reject the suggestion; editing is practiced in module 7.

3. The same in VS Code

Requires: a Pro plan and VS Code. No Pro? Follow the instructor's demo (Max) or work with a partner.

Install the VS Code extension, open the folder from exercise 2 in VS Code and open the script. Select a few lines of the script, add the selection to the conversation (Alt+K) and ask: "Explain these lines line by line."

Show example answer

Claude explains exactly the selected lines without you copying them into the conversation. If the extension does not show, restart VS Code or run Developer: Reload Window. Note that this is the same Claude Code as on the command line: sessions and settings are shared.

Optional: troubleshooting and WSL

  • Installation fails (403 or another error): a corporate proxy or filter may block the download. Try the CMD or WinGet alternative and see installation troubleshooting.
  • Claude Code cannot find Git Bash: in the env block of the settings file you can set the variable CLAUDE_CODE_GIT_BASH_PATH to the path of bash.exe.
  • WSL: if you work with Linux tools, install Claude Code inside WSL with the Linux command and start it in a WSL terminal. Then sandboxing is also available, which native Windows does not support.
  • Uninstalling: a native installation is removed by deleting the program file and the version folder (instructions on the installation page); a WinGet installation with the command winget uninstall Anthropic.ClaudeCode.
  • Version: claude --version shows the version. If a menu or command in this course does not match yours, check your version and compare it with the version tested for the course, 2.1.318.

Optional: a usage meter for VS Code

The extension Claude Code Usage (identifier growthjack.claude-code-usage) shows the token usage, cache and quota of Claude Code (and OpenAI Codex) in the VS Code status bar.

A third-party extension, not Anthropic's. The publisher is GrowthJack, and the page has no verified-publisher badge. Before installing, check the publisher and whether your organization's guidance allows the extension. You can always see the official figures in Claude Code with the command /usage.
