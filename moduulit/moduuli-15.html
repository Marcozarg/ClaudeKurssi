Claude API ja Agent SDK

Ydin ~25 minLisä ~20 minAPI-avain

API ja tilaus ovat eri asioita

Tähän asti olet käyttänyt Claudea claude.ai:ssa ja Claude Codessa tilauksella (Free, Pro tai Max). Claude API on tapa kutsua Claudea omasta koodista: skriptistä, palvelusta tai integraatiosta. Se on eri tuote kuin tilaus:

  • Erillinen laskutus: API laskutetaan käytön mukaan, tokeneittain, Claude Consolessa (platform.claude.com). Pro- tai Max-tilaus ei sisällä API-käyttöä, eikä API-käyttö kuluta tilauksen rajaa.
  • API-avain: koodi tunnistautuu avaimella, jonka luot Consolessa. Avain on salaisuus samalla tavalla kuin salasana (moduuli 0): se ei kuulu koodiin, gitiin, keskusteluun eikä kuvakaappaukseen.
  • Kulurajat: aseta Consolessa kuukausiraja, ennen kuin ajat mitään silmukassa. Virheellinen silmukka voi kuluttaa rahaa nopeasti.
Työpaikalla API-avaimen ja laskutuksen omistaa yleensä organisaatio. Kysy ennen kuin luot avaimen työkäyttöön tai liität työn dataa API-kutsuun.

Ensimmäinen kutsu Pythonilla

Asenna Anthropicin Python-kirjasto ja anna avain ympäristömuuttujana. Alla oleva PowerShell-rivi asettaa muuttujan vain tähän ikkunaan, joten avain ei jää tiedostoon.

pip install anthropic
$env:ANTHROPIC_API_KEY = "liitä-avain-tähän"

Tallenna tiedostoon ensimmainen.py ja aja python ensimmainen.py:

import anthropic

client = anthropic.Anthropic()
response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "Selitä yhdellä virkkeellä, mitä DNS tekee."}],
)
for block in response.content:
    if block.type == "text":
        print(block.text)
print("tokenit sisään:", response.usage.input_tokens, "ulos:", response.usage.output_tokens)
  • anthropic.Anthropic() lukee avaimen muuttujasta ANTHROPIC_API_KEY. Älä kirjoita avainta koodiin.
  • model on mallin tunnus, max_tokens vastauksen yläraja.
  • Vastaus on lista lohkoja; tekstilohkot tulostetaan. usage kertoo, kuinka monesta tokenista maksat.

Mallin valinta ja hinta

Sama hinnasto kuin moduulissa 0, nyt mallin tunnuksen kanssa. Hinnat dollareina miljoonaa tokenia kohden, tarkistettu 11/2026 (Pricing):

MalliTunnusSyöteTulosteMilloin
Haiku 5.5claude-haiku-5-50,10 $0,50 $Suuret määrät yksinkertaista työtä: luokittelu, poiminta. Hinta koskee enintään 100 000 tokenin kehotteita.
Sonnet 5.5claude-sonnet-5-52 $10 $Arkinen koodi ja tekstityö nopeasti.
Opus 5.5claude-opus-5-54 $20 $Oletusvalinta vaativaan työhön.
Fable 5.1claude-fable-5-110 $50 $Vaikeimmat tehtävät, kun laatu ratkaisee.

Laske ennen kuin ajat: 1 000 tikettiä, joissa kussakin 2 000 tokenia sisään ja 300 ulos, on 2 miljoonaa syötetokenia ja 0,3 miljoonaa tulostetokenia. Haikulla se maksaa noin 0,35 $, Opuksella noin 14 $. Kun tehtävä on yksinkertainen ja toistuva, kokeile ensin halvempaa mallia ja tarkista tulos muutamasta esimerkistä.

Mallit ajattelevat ennen vastausta, ja ajattelu laskutetaan tulostetokeneina. Ajattelun määrää säädetään parametrilla output_config={"effort": "low"} (myös medium, high, xhigh, max); kevyt tehtävä ei tarvitse korkeaa effortia.

Agent SDK lyhyesti

Yksi API-kutsu on yksi kysymys ja yksi vastaus. Kun haluat ohjelman, joka lukee tiedostoja, ajaa komentoja ja tekee monta askelta itse, tarvitset agentin. Kolme tapaa:

TapaMitä saatMilloin
API-kutsuVastaus kehotteeseen. Työkalut ja silmukan teet itse.Luokittelu, tiivistys, poiminta omassa skriptissä.
claude -pClaude Code skriptissä tai CI:ssä (moduuli 14).Valmis Claude Code ajettuna ilman käyttäjää.
Agent SDKClaude Code kirjastona Pythoniin tai TypeScriptiin: valmiit työkalut (tiedostot, komennot, haku), luvat, hookit ja subagentit.Oma ohjelma tai palvelu, jonka sisällä toimii agentti.

Agent SDK käyttää samoja lupia ja turvarajoja kuin Claude Code (moduulit 7 ja 12): agentti, joka saa ajaa komentoja, tarvitsee yhtä tiukat rajat kuin Claude Code. Dokumentaatio ja esimerkit: code.claude.com/docs/en/agent-sdk.

Harjoitukset

1. Ensimmäinen API-kutsu

Edellyttää: API-avain Consolessa, saldoa ja Python 3. Ei avainta? Liitä skripti claude.ai-keskusteluun (Free) ja pyydä Claudea selittämään se rivi riviltä ja kertomaan, mitä se tulostaa.

Aja osion "Ensimmäinen kutsu Pythonilla" skripti. Vaihda sitten malliksi claude-haiku-5-5 ja aja uudelleen. Vertaa vastauksia ja tokenimääriä, ja laske kummankin kutsun hinta taulukon hinnoilla.

Näytä esimerkkivastaus

Skripti tulostaa yhden virkkeen (esimerkiksi "DNS muuttaa verkkotunnukset IP-osoitteiksi, jotta koneet löytävät toisensa.") ja tokenimäärät, tyypillisesti muutama kymmenen sisään ja muutamasta kymmenestä muutamaan sataan ulos, koska ajattelu lasketaan tulosteeseen. Kumpikin kutsu maksaa alle sentin. Jos saat virheen authentication_error, muuttuja puuttuu tai avain on väärä: aseta muuttuja samassa PowerShell-ikkunassa, jossa ajat skriptin.

2. Laske kustannus ennen ajoa

Edellyttää: ei mitään; laskin tai claude.ai (Free) riittää.

Aiot luokitella 500 tikettiä. Kussakin on noin 1 500 tokenia sisään ja 200 ulos. Laske hinta Haikulla, Sonnetilla ja Opuksella taulukon hinnoilla.

Näytä esimerkkivastaus

Syötettä on 500 × 1 500 = 750 000 tokenia (0,75 miljoonaa), tulostetta 500 × 200 = 100 000 tokenia (0,1 miljoonaa). Haiku: 0,75 × 0,10 + 0,1 × 0,50 = noin 0,13 $. Sonnet: 0,75 × 2 + 0,1 × 10 = 2,50 $. Opus: 0,75 × 4 + 0,1 × 20 = 5 $. Luokittelu on yksinkertaista työtä, joten aloita Haikulla ja tarkista tulos muutamasta tiketistä käsin.

3. Luokittele tiketit

Edellyttää: API-avain, saldoa ja Python 3. Ei avainta? Anna sama ohje ja tiketit claude.ai-keskustelussa (Free) ja vertaa tulosta esimerkkivastaukseen.

Skripti luokittelee kolme keksittyä tikettiä Haikulla matalalla effortilla. Aja se ja tarkista, ovatko luokat oikein. Lisää sitten oma tiketti listaan.

import anthropic

client = anthropic.Anthropic()
tiketit = [
    "Tulostin kolmannessa kerroksessa ei tulosta, valo vilkkuu oranssina.",
    "Unohdin salasanani enkä pääse kirjautumaan koneelle.",
    "Tarvitsen Visio-lisenssin projektia varten.",
]
for tiketti in tiketit:
    vastaus = client.messages.create(
        model="claude-haiku-5-5",
        max_tokens=1000,
        output_config={"effort": "low"},
        system="Luokittele IT-tiketti yhteen luokkaan: laitteisto, tunnukset, ohjelmisto tai muu. Vastaa pelkällä luokan nimellä.",
        messages=[{"role": "user", "content": tiketti}],
    )
    luokka = next(b.text for b in vastaus.content if b.type == "text").strip()
    print(f"{luokka}: {tiketti}")
Näytä esimerkkivastaus

Odotettu tulos: tulostin on laitteisto, salasana tunnukset ja Visio-lisenssi ohjelmisto. Järjestelmäkehote (system) on sama joka kutsussa, ja vain tiketti vaihtuu. Jos luokka tulee lauseena eikä pelkkänä sanana, tarkenna ohjetta tai pyydä vastaus JSON-muodossa. Ennen kuin ajat tuhansia tikettejä, tarkista tulos pienestä otoksesta käsin ja laske hinta kuten harjoituksessa 2.

Lisä: työkalut, välimuisti ja muuta

  • Työkalut (tool use): määrittelet funktion nimen, kuvauksen ja parametrit, ja Claude pyytää kutsua sitä, kun tarvitsee tietoa tai toimintoa. Sinun koodisi ajaa funktion ja palauttaa tuloksen. Näin Claude voi esimerkiksi hakea tiketin tilan omasta järjestelmästäsi. Ohje: Tool use.
  • Välimuisti (prompt caching): kun sama pitkä alku (järjestelmäkehote, ohjeet, dokumentti) toistuu monessa kutsussa, se voidaan tallentaa välimuistiin, ja uudelleen luettuna se maksaa noin kymmenesosan. Yksinkertaisin tapa on yksi parametri: 
    response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=16000,
    cache_control={"type": "ephemeral"},
    system="Pitkä ohje, joka on sama joka kutsussa...",
    messages=[{"role": "user", "content": "Tiivistä tämä tiketti."}],
)
print(response.usage.cache_read_input_tokens)
    Välimuisti toimii vain, kun alku on joka kutsussa täsmälleen sama: aikaleima kehotteen alussa estää sen. Ohje: Prompt caching.
  • Erätyöt (Batches): kun tulos saa tulla myöhemmin, erä-API maksaa noin puolet tavallisesta.
  • Miksi vastaus päättyi: response.stop_reason on tavallisesti end_turn; max_tokens tarkoittaa, että raja tuli vastaan, ja refusal, että malli kieltäytyi. Tarkista se ennen kuin luet vastauksen.
