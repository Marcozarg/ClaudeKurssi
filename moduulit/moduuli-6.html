Claude Code: asennus

Ydin ~20 minLisä ~15 minPro / Max

Mikä Claude Code on?

Claude Code on Clauden versio, joka toimii koneellasi omassa kansiossasi. Se lukee tiedostoja, muokkaa niitä ja ajaa komentoja (esimerkiksi PowerShell-skriptejä ja git-komentoja), kun hyväksyt sen. Chatissa sinä kopioit tekstin Claudelle ja takaisin. Claude Codessa Claude työskentelee suoraan tiedostojesi kanssa.

  • Sopii skriptien, lokien, ohjeiden ja konfiguraatioiden työstämiseen, ei vain ohjelmointiin.
  • Käytettävissä komentorivillä, VS Code -laajennuksena ja työpöytäsovelluksen Code-välilehdellä. Kaikki käyttävät samoja asetuksia.
  • Käyttö kuluttaa samaa käyttörajaa kuin claude.ai (moduuli 0, käyttörajat).
Claude Code vaatii Pro-, Max-, Ultra-, Team- tai Enterprise-tilauksen tai Console-tilin. Ilmainen claude.ai-tilaus ei sisällä Claude Codea. Ei Prota? Seuraa kouluttajan demoa tai tee parin kanssa.

Ennen asennusta

  • Windows: Windows 10 versio 1809 tai uudempi, tai Windows Server 2019 tai uudempi.
  • Laitteisto: vähintään 4 Gt RAM, x64- tai ARM64-suoritin, internet-yhteys.
  • Järjestelmänvalvojan oikeuksia ei tarvita. Älä avaa terminaalia järjestelmänvalvojana.
  • Git for Windows on valinnainen mutta suositeltava. Ilman sitä Claude Code käyttää komentojen ajamiseen PowerShelliä; sen kanssa se käyttää Git Bashia. Moduulissa 8 tarvitaan joka tapauksessa git.

Kurssin testattu Claude Code -versio on 2.1.318 (tarkistettu 11/2026). Uudemmassa versiossa valikot ja komennot voivat poiketa hieman; asennusohje on aina ajantasainen.

Asennus Windowsiin

Avaa PowerShell (Käynnistä-valikosta) ja aja:

irm https://claude.ai/install.ps1 | iex

Asennus ei näytä edistymistä latauksen aikana. Kun se on valmis, avaa uusi terminaali-ikkuna ja tarkista:

claude --version

Komento tulostaa versionumeron. Jos terminaali sanoo, ettei claude ole tunnettu komento, asennushakemisto ei ole vielä PATH-muuttujassa; uusi terminaali ratkaisee yleensä asian.

Ensimmäinen käynnistys ja kirjautuminen

  1. Siirry kansioon, jossa haluat työskennellä, esimerkiksi harjoituskansioon: cd %USERPROFILE%\Documents\harjoitus (CMD) tai cd $env:USERPROFILE\Documents\harjoitus (PowerShell).
  2. Kirjoita claude.
  3. Ensimmäisellä kerralla Claude Code avaa selaimen. Kirjaudu samalla Claude-tilillä, jolla on Pro tai Max.
  4. Claude Code kysyy, luotatko kansioon. Vastaa kyllä vain kansioille, joiden sisällön tunnet.
  5. Kirjoita viesti, esimerkiksi "Mitä tässä kansiossa on?", ja katso, miten Claude pyytää lupaa lukea tiedostoja.
[KUVA: m6-login - selaimen kirjautumisikkuna ja valmis istunto]

Voit tarkistaa asennuksen tilan komennolla claude doctor. Natiivi asennus päivittyy itse; muut asennustavat tarvitsevat päivityksen käsin (claude update natiiville asennukselle).

VS Code -laajennus

  1. Avaa VS Code (versio 1.94.0 tai uudempi).
  2. Avaa Extensions (Ctrl+Shift+X), hae "Claude Code" ja valitse Install. Laajennuksen tunnus on anthropic.claude-code.
  3. Avaa Claude: napsauta Spark-kuvaketta editorin oikeasta yläkulmasta (näkyy, kun tiedosto on auki) tai alapalkin Claude Code -tekstiä.
  4. Jos laajennus ei näy asennuksen jälkeen, käynnistä VS Code uudelleen tai aja komentopaletista (Ctrl+Shift+P) Developer: Reload Window.

Hyöty: Claude näkee avoimen tiedostosi ja valintasi, ja muutokset näkyvät editorissa diffinä, jonka hyväksyt tai hylkäät. Alt+K lisää keskusteluun viittauksen nykyiseen tiedostoon ja valintaan.

[KUVA: m6-vscode - VS Code, Claude Code -paneeli ja ehdotettu muutos diffinä]

Työpöytäsovellus: Code-välilehti

Jos olet jo asentanut Clauden työpöytäsovelluksen (moduuli 4), Claude Code on sen Code-välilehdellä. Erillistä komentorivi-asennusta tai Node.js:ää ei tarvita.

  1. Avaa sovellus ja kirjaudu sisään.
  2. Valitse sivupalkin yläreunasta Code.
  3. Valitse ympäristöksi Local ja avaa työkansio (Open folder...).
  4. Valitse malli ja kirjoita, mitä Claude tekee.

Lupatila näkyy kehotekentän alla: Manual kysyy ennen muutoksia, Accept edits hyväksyy tiedostomuutokset itse, Plan vain suunnittelee. Aloita Manualilla. Muutokset näet diff-näkymässä.

Harjoitukset

1. Asenna ja tarkista

Edellyttää: Pro-tilaus. Ei Prota? Seuraa kouluttajan demoa (Max) tai tee parin kanssa.

Asenna Claude Code PowerShellillä, avaa uusi terminaali ja kirjaudu sisään. Pyydä Claudea kertomaan, mikä Windows-versio koneessa on ja onko git asennettu. Vertaa vastausta itse ajamiisi komentoihin winver ja git --version.

Näytä esimerkkivastaus

Claude ehdottaa komentoja (esimerkiksi Get-ComputerInfo ja git --version) ja pyytää lupaa ajaa ne. Kun hyväksyt, se kertoo version ja sen, onko git käytettävissä. Jos git puuttuu, Claude kertoo sen virheilmoituksesta; asenna silloin Git for Windows ennen moduulia 8. Tarkista, että Clauden kertoma versio täsmää winver-ikkunan kanssa.

2. Kysy tiedostoista

Edellyttää: Pro-tilaus. Ei Prota? Seuraa kouluttajan demoa (Max) tai tee parin kanssa.

Tee tyhjä kansio, jossa on yksi PowerShell-skripti (esimerkiksi levytilaa tarkistava) ja pieni lokitiedosto. Käynnistä claude kansiossa ja kysy: "Mitä näissä tiedostoissa on? Tiivistä skripti kahteen lauseeseen ja kerro, mitä lokissa näkyy." Huomaa, miten Claude pyytää lupaa lukea tiedostot.

Näytä esimerkkivastaus

Claude lukee kansion tiedostot (lukeminen työkansiossa ei yleensä kysy lupaa), tiivistää skriptin ja nostaa lokista toistuvat virheet. Tarkista, että tiivistys vastaa skriptin todellista toimintaa: avaa skripti ja vertaa. Jos Claude ehdottaa skriptin muuttamista, hylkää ehdotus; muokkaamista harjoitellaan moduulissa 7.

3. Sama VS Codessa

Edellyttää: Pro-tilaus ja VS Code. Ei Prota? Seuraa kouluttajan demoa (Max) tai tee parin kanssa.

Asenna VS Code -laajennus, avaa harjoituksen 2 kansio VS Codessa ja avaa skripti. Valitse skriptistä muutama rivi, lisää valinta keskusteluun (Alt+K) ja pyydä: "Selitä nämä rivit rivi riviltä."

Näytä esimerkkivastaus

Claude selittää juuri valitut rivit ilman, että kopioit niitä keskusteluun. Jos laajennus ei näy, käynnistä VS Code uudelleen tai aja Developer: Reload Window. Huomaa, että tämä on sama Claude Code kuin komentorivillä: istunnot ja asetukset ovat yhteisiä.

Lisä: ongelmatilanteet ja WSL

  • Asennus epäonnistuu (403 tai muu virhe): yritysverkon välityspalvelin tai suodatin voi estää latauksen. Kokeile CMD- tai WinGet-vaihtoehtoa ja katso asennuksen vianmääritys.
  • Claude Code ei löydä Git Bashia: asetustiedoston env-lohkoon voi asettaa muuttujan CLAUDE_CODE_GIT_BASH_PATH, jonka arvo on bash.exe:n polku.
  • WSL: jos työskentelet Linux-työkalujen kanssa, asenna Claude Code WSL:n sisälle Linux-komennolla ja käynnistä se WSL-terminaalissa. Silloin käytettävissä on myös hiekkalaatikko (sandboxing), jota natiivi Windows ei tue.
  • Asennuksen poisto: natiivi asennus poistetaan poistamalla ohjelmatiedosto ja versiohakemisto (ohjeet asennussivulla); WinGet-asennus komennolla winget uninstall Anthropic.ClaudeCode.
  • Versio: claude --version kertoo version. Jos jokin tämän kurssin valikko tai komento ei vastaa omaasi, tarkista versio ja vertaa kurssin testattuun versioon 2.1.318.
